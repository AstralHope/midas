欢迎使用 MIDAS 中间件综合诊断分析系统

MIDAS (Middleware Integrated Diagnostic Analysis System) —— 面向中间件与云原生环境的一体化运维信息聚合与智能诊断工作台，助您高效掌控基础设施全景。

☁️ 云上信息中心
节点 Pod 信息

自动归集各 ACK 集群的节点与 Pod 运行状态，支持多条件筛选过滤、多列排序、导出 CSV 及一键下钻查看 Pod 明细文本。

ACK 集群信息

聚合多云环境下的 ACK 生产集群概况与节点拓扑，Master 节点智能优先置顶，集群健康与规模一目了然。

SOFAMQ 信息

展示各区域与集群的 SOFAMQ 消息队列运行参数与组件配置，方便快速核对消息中间件拓扑。

🏢 云下中间件资产
Nginx 实例与在线配置

汇聚各 ECS 主机中 Nginx 实例的 IP、端口、运行用户、PID、安装路径与版本信息，支持点击直接在线预览查看对应 Nginx 配置文件。

Tomcat 实例管理

集中展示各业务环境 Tomcat 容器的部署路径、版本及运行参数，统一管理传统中间件资产。

🛠️ 实用诊断小工具
VSW 网段智能匹配

网络运维排查利器。输入任意 IP 地址，系统自动计算子网掩码并秒级匹配所属的虚拟交换机（VSW）、所属云、CIDR 网段及有效 IP 范围。

JavaCore 线程栈分析

集成可视化 Java 线程堆栈分析工具，支持线程状态统计、死锁自动检测与阻塞调用链图谱，快速诊断 CPU 飙高和线程卡死。

Jifa 堆内存深度分析

集成 Eclipse Jifa 故障诊断平台，基于 Eclipse MAT 底层能力，支持在线上传并深度解析 Java 堆转储文件（Heap Dump）、GC 日志与 JFR 文件。

💡 使用小贴士：
  • • 数据交互：所有信息表格均支持关键词快速模糊搜索、分页切换、表头点击排序及结果导出为 CSV 文件。
  • • 实时监控：点击右上角导航栏的 Nginx-vts 可快速打开当前环境的 Nginx 流量与状态实时监控面板。
  • • 安全退出：使用完毕后可点击右上角「退出」按钮安全登出会话。
